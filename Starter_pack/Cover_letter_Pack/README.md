# Cover_letter_Pack

Configura un assistente personalizzato per le candidature a partire dal CV, dalle preferenze e da 2–3 cover letter di esempio.

## Come usarlo

Incolla integralmente [PROMPTME.md](PROMPTME.md) nella chat. PROMPTME contiene le istruzioni per chiedere il CV, chiarire priorità e stile, raccogliere esempi e produrre le istruzioni personalizzate del progetto.

Il prompt iniziale non va incollato nelle istruzioni avanzate: in quel campo va il blocco finale personalizzato generato dopo le risposte. Quel blocco deve essere contato automaticamente e restare al massimo di 7.500 caratteri, quindi inferiore a 8.000. Se manca uno strumento di conteggio, deve essere dichiarato non verificato.

Aggiungi CV ed esempi alle fonti del progetto; le lettere sono riferimenti di stile, non prove di esperienze. Poi fornisci l'annuncio e usa il workflow ricerca, confronto, scrittura e revisione. Gli strumenti per web, file e Progetti dipendono dall'ambiente disponibile.

Questo pack è autonomo come prompt e non richiede gli agenti di sviluppo software. PROMPTME.md è una copia esportata di Prompts/CoverLetter.md nel repository canonico; gli aggiornamenti non si propagano automaticamente. Non condividere un pack personalizzato contenente dati del candidato senza rimuoverli.
